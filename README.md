# Beanie — Coffee Shop HTML Template (FREE)

Beanie is a warm, modern **Bootstrap 5** HTML template for coffee shops, cafés and roasteries.

This is the **free edition** — a single, fully-built **homepage** (`index.html`) so you can try the design, layout and code quality before upgrading.

> Want the rest of the site? The **PRO** edition adds **9 more pages** — About, Menu, Shop, Product Details, Blog, Blog Details, Gallery, FAQs and a working Contact form — plus a filterable shop grid, blog sidebar, lightbox gallery and more. Get it at **[templatesjungle.com](https://templatesjungle.com)**.

## What's Included

- `index.html` — the complete homepage: hero, featured products, shop-by-category, new arrivals / best sellers, newsletter box, feature strip, blog teaser, Instagram strip and footer.
- `assets/` — all CSS, JS, fonts references, icons and the images used on the homepage.

The header's **Home** link is fully working. All other navigation items (Shop, Blog, Pages, Contact) are labeled **PRO** and link out to [templatesjungle.com](https://templatesjungle.com), since those pages only exist in the paid template.

## Getting Started

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx http-server . -p 8080
```

## Structure

```
Beanie - Coffee Shop Free HTML Template/
├── index.html
└── assets/
    ├── css/style.css        → design tokens & all component styles
    ├── js/script.js         → nav shadow, back-to-top, newsletter form demo
    ├── img/                 → homepage photography
    └── vendor/
        ├── bootstrap/            → Bootstrap 5.3 (CSS + bundled JS)
        └── bootstrap-icons/      → Bootstrap Icons 1.11
```

## Customizing

All colors, fonts and spacing are defined as CSS variables at the top of `assets/css/style.css` (`:root`) — change `--clr-accent`, `--clr-dark`, etc. to re-theme the page. Headings use [Fraunces](https://fonts.google.com/specimen/Fraunces) and body text uses [Jost](https://fonts.google.com/specimen/Jost), both loaded from Google Fonts.
